# Human-Benchmark
This is based on the real Website Human Benchmark and consists of Memory Training Games reflecting the real like Human Benchmark.
Link: "https://humanbenchmark.com/"


This is a Work in Progress (not completed yet)

# Features
* Different Buttons indicating the different sections wherever necessary
* Reaction Time Test (Functional)
* Typing Test (Functional)
* Verbal Memory (Functional)
* Sequence Test (Needs working)
* Aim Trainer (Needs Working)
* Number Memory (Needs Working)
* Chimp Test (Needs Working)
* Visual Memory (Needs Working)

# Running the Project
* Please ensure that you have an appropriate IDE installed (preferably VSCode but Webstorm too) with a Live Server and preview for the contents!
* Please ensure that you also have HTML and CSS installed as the project is written in these 3 languages.
* When running a Live Server (please ensure that its the HTML File that is running)
